
# Programação para Ciência de Dados 📊

Repositório acadêmico da disciplina de **Programação para Ciência de Dados**, cursada na Universidade Regional do Noroeste do Estado do Rio Grande do Sul (UNIJUÍ).

Este repositório reúne exercícios, atividades práticas e materiais desenvolvidos ao longo da disciplina, com foco no aprendizado de programação em Python e conceitos relacionados à Ciência de Dados.

## 📚 Conteúdos abordados

- Fundamentos de programação em Python
- Estruturas de dados e manipulação de arquivos
- Programação Orientada a Objetos (POO)
- Algoritmos e resolução de problemas
- Introdução ao uso de Git e GitHub
- Utilização de Jupyter Notebook e Google Colab
